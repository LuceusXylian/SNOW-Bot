SNOW Bot User Guide

SNOW Bot is a browser automation assistant for form filling, recurring workflows, and browser-triggered actions. Use the popup to manage templates, scripts, triggers, button shortcuts, and chat-driven commands.

1. Enable the Bot

Open the extension popup and click the power button at the top right to toggle running mode. The bot must be enabled before templates or scripts can execute.

2. Templates

Templates let you insert reusable text into web inputs or textareas.

  • Create a template: enter a name and content, then click Save Template.
  • Edit a template: click Edit next to the template, update fields, and save.
  • Delete a template: click Delete.
  • Insert a template: focus a page input or textarea, then click Execute Insert on the saved template.

Templates support shortcodes in the form [FieldName] or list form [Caller|Created for]. When executed, SNOW Bot resolves the first matching label and insert its corresponding formcontrol value into the field.

3. Script Editor

The Script Editor lets you build custom automation workflows with conditions and actions.

  • Conditions check page state, URL, hostname, element values, or attributes.
  • Actions interact with the page: insert templates, set or get element attributes, trigger events, send notifications, wait, or loop over matching elements.
  • Run scripts from the editor or using triggers and button grid shortcuts.

Scripts are useful for multi-step interactions such as filling fields, clicking buttons, or validating page content before continuing.

4. Triggers

Triggers run scripts automatically when specified conditions are met.

  • Page event triggers: fire when the browser sees a matching URL, hostname, or element state.
  • Timer triggers: run scripts every few seconds if enabled.
  • Trigger actions: can execute scripts when the trigger conditions are satisfied.

Use triggers for scheduled checks or to launch workflows automatically when you open or interact with a page.

5. Button Grid

The Button Grid gives you a quick-launch panel for scripts.

  • Create button profiles and assign scripts to each button.
  • Use the grid to execute scripts with one click.
  • Customize grid size and button layout to fit your workflow.

6. Chat

The Chat section provides a searchable interface for script execution.

  • Search for scripts by name or keyword.
  • Execute scripts directly from the chat interface.
  • View progress updates and results in the chat history area.

7. Logs

The Logs section shows recent activity and execution history. Use it to troubleshoot failed scripts or confirm that actions ran.

8. Settings

Under Settings, you can import or export your stored configuration and automation definitions as JSON.

  • Export Settings: save your templates, scripts, triggers, and button grid profiles.
  • Import Settings: restore or transfer settings between browsers.
  • Predefined persistent variables: define global variables that apply to every profile and optional profile-specific variables that override them for the selected button-grid profile.

9. Predefined persistent variables

The predefined persistent variable editor keeps reusable values in a single place for scripts and templates. Values are split into two scopes:

  • Global: values saved here are available for every profile.
  • Profile: values saved for the active profile override global values only while that profile is selected.

When you switch profiles, the previous profile values are cleared and the active profile values are rebuilt from the selected profile plus the global defaults. This keeps the current persistent variable map aligned with the selected profile and avoids leaking stale values.

10. Troubleshooting

  • Keep the bot enabled and ensure the target input or textarea is focused before executing a template.
  • Use clear CSS selectors in scripts and triggers. If an element id ends with 3 numeric characters, it may be autogenerated and that is why the element selector generator will use htmltag[name='$name'] as selector.
  • Test scripts on the target page to verify correct behavior before relying on automation.
  • If a template does not insert, verify the bot is running and the page field is focused. If a script does not run, check the trigger conditions and page hostname/URL filters.
  • Review the Logs page for error messages and execution details.
