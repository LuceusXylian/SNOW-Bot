# SNOW-bot Privacy Policy

Last updated: 2026-05-18

Summary
- SNOW-bot does not collect personal data for transmission to the developer or any third parties.
- Some information may be stored locally in the user's browser by a local logger for debugging or feature purposes.

What we collect
- No personal data is intentionally collected or transmitted off the user's device.
- The local logger may store non-personal runtime or state information in the browser (for example: timestamps, error messages, feature usage flags, or other diagnostic data). This data is stored only on the user's device.

Data transmission
- No data, personal or otherwise, is sent to the developer or any external party by SNOW-bot.

Data storage and retention
- Any data created by the local logger remains in local browser storage (e.g., localStorage, IndexedDB) and is subject to the user's browser policies and controls.
- Users can clear their browser storage at any time to remove locally stored logs and data.

Security
- SNOW-bot follows basic security practices for client-side code. Because no data is transmitted externally, risk related to sending data off-device is not applicable.

Contact
- If you have questions about this policy, contact the project maintainer via the project's repository or contact channels.

By using SNOW-bot you agree to this privacy approach: no data is sent externally and only local browser storage may be used for logging purposes.
